# Rio Tinto Branding Guidelines

## Company Identity
- **Company Name**: Rio Tinto
- **Industry**: Global Mining & Metals
- **Primary Color**: #EA0E30 (Rio Tinto Red)
- **Tagline**: "Finding better ways to provide the materials the world needs"

## Mining Operations Context
When generating code or content, always consider:
- Safety-first mindset in all mining operations
- Global operations across multiple continents
- Focus on sustainable mining practices
- Personnel management for remote mining sites
- Complex logistics and supply chain operations

## UI/UX Guidelines
- Use Rio Tinto red (#EA0E30) as primary color
- Maintain professional, industrial aesthetic
- Prioritize functionality and safety in interface design
- Consider mobile-first for field operations
- Use mining-related iconography where appropriate

## Content Guidelines
- Always use proper mining terminology
- Reference real Rio Tinto operations when creating examples:
  - Iron Ore Western Australia
  - Oyu Tolgoi Mongolia
  - Kennecott Utah
  - Diavik Diamond Mine
  - Simandou Guinea
  - Rincon Lithium
- Focus on operational efficiency and safety compliance
- Use professional, corporate tone in all communications

## Code Standards
- Follow established project patterns from global-config.ts
- Maintain MVVM architecture as specified in PRD
- Use established component library and design system
- Ensure all mining-specific features align with real-world operations
